# Álgebra Lineal
Repositorio para la asignatura  Álgebra Lineal, en el 1er semestre  para estudiantes de Ingeniería Mecánica, Cetys Universidad. Campus Tijuana.
## Propósito general del curso
El curso confiere conocimientos introductorios en teoría de matrices y álgebra lineal. Se da un énfasis en tópicos prácticos útiles en múltiples disciplinas, tales como: sistemas de ecuaciones, espacios vectoriales, proyecciones, entre otros tópicos.
