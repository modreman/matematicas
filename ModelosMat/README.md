# Modelos matemáticos de Sistemas Mecánicos 
Repositorio para la asignaturaModelos matemáticos de Sistemas Mecánicos , en el 5to semestre para estudiantes de  Ingeniería Mecánica, Cetys Universidad. Campus Tijuana.

## Propósito general del curso
Este curso tiene como propósito que el alumno utilice conocimientos matemáticos para representar fenómenos físicos por medio de ecuaciones, que son aplicables a una amplia gama de problemas de ingeniería.

## Competencia general del curso 
 Crear modelos de fenómenos físicos para el diseño y evaluación de nuevas tecnologías y solución de problemas de índole industrial mediante el uso de herramientas y métodos matemáticos
